# SOS Focinho Carente — React + Vite

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar produção

```bash
npm run build
npm run preview
```

### Estrutura
- React Router para as 9 páginas.
- Layout compartilhado para navbar, footer, tema e navegação mobile.
- Dark mode persistido no localStorage.
- Filtros de adoção e FAQ controlados no ciclo de vida do React.
- Conteúdo institucional preservado a partir dos HTMLs enviados.
